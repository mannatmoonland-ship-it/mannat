Welcome

This guide explains how to use the construction records, workforce, materials, payment, and drawing tools available in Mannat Moon Construction. Follow the steps for the module you need; options may vary by your account role.

1. Introduction

Mannat Moon Construction helps staff keep project information together: daily site reports, trade and worker details, material activity, labour payments, and construction drawings.

Site supervisors and office staff can use the operational modules available to their account. Super Admins also manage users and access administration tools. If a module is missing from your Dashboard, ask your administrator which access is appropriate.

2. Login and Account Management

Log in

  1. Open the Mannat Moon Construction sign-in page.
  2. Enter the username and password provided by your administrator, then select Sign In.
  3. If asked to change your password before continuing, complete that step first.

Change your password

  1. Open the Change Password page.
  2. Enter your current password, then enter and confirm your new password.
  3. Use at least 8 characters, including an uppercase letter, a lowercase letter, a number, and a special character. Select Update Password.

If you cannot sign in, use Forgot Password? on the sign-in page if it is available, or contact your administrator.

Log out

Select Logout in the Dashboard header when you have finished. Do not share your sign-in details with another person.

3. Dashboard Navigation

  1. After signing in, use the Dashboard cards to open a module.
  2. Choose Daily Reports for site records, Material Builder for material activity, Labour Payments for payment records, or Drawings Library for plans.
  3. Use Trade Builder to maintain trades and worker categories when that card is available to your role.
  4. Select Dashboard from a module page to return. Use Logout when finished.

Some Dashboard cards, including Trade Builder, User Management, Snapshot, and Developer Documentation, are shown only to Super Admins.

4. Daily Reports

Daily Reports show construction activity for one selected date. A report can include a trade, worker counts, weather, materials, notes, and links to visual evidence.

Choose a date and view reports

  1. Open Daily Reports from the Dashboard.
  2. Use Previous Day or Next Day to move one day, or select Today.
  3. Select Go to Date to open the calendar, then choose a date. Reports for that date appear below.

Add or edit a daily record

  1. Select + Daily Record.
  2. Enter the date, work or activity, and trade. Add location, weather, worker counts, materials, and work notes as needed.
  3. Under Visual Evidence, add a Photo or Video item and enter its title and share link. Use the preview when available.
  4. Select Save Daily Record. To change a saved record, select Edit on that record, make changes, and save again.

Use Delete on a record only when it should be removed; confirm the prompt to proceed. Daily Reports record worker counts by category, not a named attendance list.

Print or export

  1. Select Print Daily Page to print the selected date.
  2. Select Export PDF to open the print dialog. Choose Save as PDF in the browser to save a PDF file.

5. Trade Builder

Trade Builder is available to Super Admins. It maintains trade names and the worker categories used by the workforce and payment screens.

  1. Open Trade Builder from the Dashboard.
  2. Enter a trade name, such as Masons, and select + Add Worker Category.
  3. For each category, enter its name and choose Daily Wage or Lump Sum.
  4. For a daily-wage category, enter the wage and effective date. For a lump-sum category, enter the agreed amount and effective date; a work description is optional.
  5. Add any other worker categories and select Save Trade. Existing trades can be selected and edited from the Trades list.

When changing a daily wage, enter the new effective date so the wage history remains useful.

6. Materials

Material Builder includes categories, suppliers, stock, purchases, and consumption. Stock is calculated from the saved purchase and consumption records.

Set up categories and suppliers

  1. Open Material Builder. In Categories, select + Create Category and enter a category name and unit.
  2. Add brands or quarries to a category when needed, then save it.
  3. Open Suppliers, select + Create Supplier, enter the required contact details, and assign the categories and brands or quarries they supply. Save the supplier.

Record a purchase or consumption

  1. Open Stock & Transactions, then choose Purchases to record received materials.
  2. Enter the date and category. For Cement, also select a brand or quarry and enter quantity and rate; the total is calculated. For other categories, enter the purchase amount.
  3. Select a supplier if applicable. A bill photo or link is optional. Select Save Purchase.
  4. For Cement use Consumption, enter the date, category, quantity, and location or floor, then save. Consumption entry is available only when a Cement category exists.
  5. Open Stock to review the calculated available quantity.

7. Labour Muster

Not Yet Available: The application does not currently provide a separate worker attendance or Labour Muster register.

You can enter total worker counts by trade category in a Daily Report. These counts are not individual attendance records and do not replace a named muster sheet.

8. Labour Payments

Labour Payments shows a selected trade's contract and payment information, including payment totals and balances.

  1. Open Labour Payments & Contract Capping from the Dashboard and select a trade.
  2. Review the trade's contract items and payment summary. Use the payment controls for the selected trade to add or edit a transaction.
  3. Choose the transaction type: Mobilization Advance, Labour Advance, Labour Settlement, or Lump-Sum Payment.
  4. Enter the date and amount being paid, choose a payment mode, and add remarks if useful. Settlement entries can also record labour earned and advance deductions; lump-sum payments are associated with a worker category.
  5. Select Save Payment. Review the updated totals and payment history.

Mobilization payments are tracked separately from the labour advance balance. Check the displayed balance before recording a settlement.

9. Drawings Library

Manage categories and drawings

  1. Open Drawings Library. Use the search field or Category filter to find drawings.
  2. Select + Create Category to add a category. Use Edit Category to rename it; a category must be empty before it can be deleted.
  3. Select Add Drawing on a category. Enter the drawing name and a Google Drive PDF link; number, revision, and description are optional.
  4. Select Save Drawing. Use Edit or Delete beside a drawing to manage it.
  5. Select Open PDF to open the linked drawing. The PDF remains in Google Drive if its library entry is deleted.

Change the order

Use the up and down arrow buttons beside a category to move it. Use the arrows beside a drawing to reorder it within its own category. The first and last items cannot move farther in that direction. The saved order remains after refresh.

10. Troubleshooting

Sign-in problems

  • Check that the username and password are entered correctly. Passwords are case-sensitive.
  • Use Forgot Password? if available. If the account is inactive or you still cannot sign in, contact your administrator.

Missing records

  • In Daily Reports, check the selected date. Records are shown for one date at a time.
  • In Drawings Library, clear the search text and choose All categories to broaden the results.
  • In Material Builder, check the selected tab and category. Refresh the page if recent changes do not appear.

PDF, photo, or video will not open

  • Check that the link is correct and that you have permission to open it. Google Drive drawings need a valid Drive PDF link.
  • If a preview is unavailable, use the original link provided with the evidence. Some video links open separately instead of playing in the report.
  • For PDF export, use the browser print dialog and choose Save as PDF. If a new tab is blocked, allow pop-ups for this application and try again.

If a problem continues, note the module and the action you were taking, then contact your administrator.
